# Experiences Images Guide

활동 및 경력(Experiences) 썸네일 이미지를 저장하고 관리하는 디렉토리입니다.

## 파일명 명명 규칙 (Naming Convention)

```text
exp-[시작연도]-[기관 또는 행사 약칭]-[활동 키워드].[확장자]
```

### 규칙 상세
* **접두사**: `exp-` (소문자 고정)
* **연도**: 4자리 시작 연도 (예: `2019`, `2022`, `2025`)
* **기관 / 단체 / 행사명**: 소문자 영문 약칭 및 하이픈 (예: `dgist`, `gist`, `kit`, `kriss`, `ieee-whc`, `kysec`)
* **활동 키워드**: 활동 내용을 대표하는 영문 키워드 (예: `robot`, `laser`, `intelligent`, `council`, `advisory`, `ugrp`)
* **권장 확장자**: `.webp` (권장), `.jpg`, `.png`

* **권장 해상도**: 가로 560px ~ 800px
* **포맷**: 웹 최적화를 위해 `.webp` 포맷 권장
