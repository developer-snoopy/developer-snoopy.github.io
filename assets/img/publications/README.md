# Publication Images Guide

논문(Publication) 썸네일 이미지를 저장하고 관리하는 디렉토리입니다.

## 파일명 명명 규칙 (Naming Convention)

```text
pub-[연도]-[학술대회 또는 저널 약칭]-[주제 키워드].[확장자]
```

### 규칙 상세
* **접두사**: `pub-` (소문자 고정)
* **연도**: 4자리 숫자 (예: `2023`, `2022`, `2020`)
* **학술대회 / 저널명**: 소문자 영문 약칭 및 하이픈 (예: `chi`, `eurohaptics`, `ieee-access`, `cvpr`)
* **주제 키워드**: 논문 내용을 대표하는 1~2개 영문 단어 (예: `tacton`, `similarity`, `laser`)
* **권장 확장자**: `.webp` (권장), `.jpg`, `.png`

## 권장 이미지 사양
* **종횡비**: 16:9 또는 4:3 (가로형)
* **권장 해상도**: 가로 560px ~ 800px (고해상도 Retina 디스플레이 대응)
* **포맷**: 웹 최적화를 위해 `.webp` 포맷 권장 (용량 절감 및 로딩 속도 최적화)
